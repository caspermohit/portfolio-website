# Skillary design polish

Medium: responsive portfolio website, with keyboard navigation, touch interaction, and reduced-motion support. The existing ivory, ink, and electric blue palette remains the design constraint.

Guidance read from Skillary's design collection:

- [Design critique](https://github.com/poorvith-mp/skills-design/blob/main/skills/design-critique/SKILL.md)

## Findings and changes

| Finding | Improvement |
| --- | --- |
| Scrolling was the only internal way to reach an individual featured work | Added a compact three-project navigation with ordinary anchor links |
| Large numbering repeated the smaller project index; giant ghost words and crosses competed with product imagery | Removed these repeated ornaments; authentic desktop and phone screenshots carry the composition |
| Project launch links had the same quiet visual weight as secondary links | Introduced a clear blue primary action and retained understated source links |
| All spreads repeated the same phone position | The third spread uses a reversed composition without changing navigation or color |
| Small descriptions and metadata reduced legibility | Increased descriptive text and metadata sizes |
| Some archive actions had narrow touch targets | Increased category and project-link targets to at least 44px tall |
| Hover effects lasted longer than needed | Preview and action microinteractions use 200–280ms timing and reduced-motion fallbacks |

No new illustrations, fonts, fictional outcomes, or project metrics were introduced. The animated hero and established scroll concept remain because the user requested motion and asked for a modest refinement.
